    Imports, copying and hashing¶

    Use the shared module loader, copy and hash helpers when the consumer contract matches. Resource extraction, diagnostic imports, memo-aware graphs, streamed hashes and binary digests retain their native interfaces.

    Operation boundaries¶

    Operation Behavior
    Graph copying No-memo value copies use the shared helper. Pile graph copies retain the caller-supplied memo across public/private state and fresh lock construction.
    Text and buffer hashing Shared hashes preserve input strings, truncation and uncapped max_bytes=None. Incremental streams and binary digest consumers keep their own interfaces.
    Incremental and binary hashes Byte/file/fd and BLAKE2b helpers serve matching consumers; streamed updates, raw 32-byte digests and pricing buffer admission remain native.
    Nominal and structural type checks Nominal model/union helpers serve matching consumers; generic containers, structural model classes and repr formatting retain their distinct rules.
    Lazy module loading CLI/state loading stays lazy. Trusted settings use module-only loading; package resources, installed metadata and file-location modules retain their own ownership.
    Module-only import helper ln.import_module retains leaf/relative loading and missing-module identity. Selected module-only callers use its ordinary ImportError normalization; genuine native diagnostic imports retain their own interfaces.
    Canonical digest inputs CLI, schedule and plugin identifiers hash their exact canonical JSON bytes; generated module names use deterministic uncapped hashes.
    Import exception diagnostics Selected shared callers expose ordinary ImportError prefix/plain class and original cause, with outer name/path set to None. ModuleNotFoundError retains its original object, subclass and metadata. Other native diagnostics remain unchanged.
    Structural model and union rendering Structural model classes are admitted with isinstance(type) and model_fields; local multi-member union preference remains distinct from nominal BaseModel checks.

    Shared helpers¶

    settings._import_hook imports ln only after colon and trust admission, then uses ln.import_module in module-only mode and retains getattr. get_class uses the same public loader only in its built-in fallback loop. Neither caller changes the independent dotted-type loader, skipped-error handling or lookup caches. copy, compute_hash, hash_file, hash_fd and the type/lazy helpers serve compatible consumers.

    The twelve selected module loads across eight application/provider files also use ln.import_module in module-only mode. An ordinary ImportError becomes a plain ImportError whose message is Failed to import module <path>: followed by a space and the original message, outer .name and .path set to None, and the original exception retained as __cause__. This is a visible diagnostic change, including the displayed class for custom ordinary ImportError subclasses. A ModuleNotFoundError is re-raised as the original object: its subclass, .name, .path and prior __cause__ remain unchanged.

    Attribute lookup and handler calls stay outside the import helper. Demand-driven loading, successful-only caching, optional-dependency preflight, registration order and existing credential masking retain their boundaries. These eight files use the shared error contract. The remaining native rows below retain their documented contracts. Existing settings/class-registry and MCP loaders keep their current behavior.

    lionagi/protocols/generic/pile.py (Pile.__deepcopy__) Native operation Pile.__deepcopy__ copies non-lock private state using the same caller-supplied memo as its public state, then creates fresh sync/async locks. ln.copy has no memo parameter; separate deep copies would break alias/cycle identity across the two state dictionaries.
    lionagi/protocols/generic/pile.py (Pile.__deepcopy__) Native operation Pile.__deepcopy__ registers result in memo before copying every __dict__ value with that memo. This preserves cycles and shared references including later private-state copies. ln.copy cannot accept that memo graph; retaining the native call is required.
    lionagi/service/accounts/_pricing.py (quote_ceiling) Native operation quote_ceiling calls _parse(body), whose json.loads accepts valid str, bytes or bytearray and has no exact-bytes guard. The native hash retains these visible admission/refusal results and the exact SHA256 body digest. Exact bytes produce the same SHA256 hexdigest under either hash interface.
    lionagi/service/connections/endpoint.py (_pinned_ssl_context._PinnedSSLObject.do_handshake) Native operation TLS pinning compares a 32-byte SHA256.digest() of the DER peer certificate to the caller-provided fingerprint. compute_hash returns hexadecimal text and accepts/serializes a broader object domain; there is no existing raw-buffer-digest helper with the same binary comparison/refusal interface.

    lionagi/service/connections/registry.py (_import_provider_module) Shared ln.import_module Keep optional-dependency preflight before shared module-only loading, with its separate declared-missing debug path. Forged name/path metadata does not reclassify a module-body bug.
    lionagi/state/lifecycle/notify_settings.py (_make_python_handler) Shared ln.import_module Use shared module-only loading, retaining getattr/callable validation outside the helper. build_handler still warns, emits the stable python_adapter_unresolvable callback and returns None on failure. The ordinary-error warning gains the shared prefix/plain class and original cause; registration/deadline behavior remains.
    lionagi/studio/config.py (_named_zone_rules) Native operation After a configured disk zone-file path is absent, timezone lookup walks tzdata.zoneinfo resources and may open a non-Path ZIP member with a bounded read into tzif_rules. Existing archive/I/O/import/refusal classes are caught. A normal filesystem/module helper cannot reproduce that Traversable/resource-stream behavior.
    lionagi/studio/launch_access.py (_digest) Native operation The capability store uses the returned 32-byte digest as dictionary identity and capability.digest, not a textual fingerprint. compute_hash returns hexadecimal text and has broader input semantics; retaining the native bytes avoids changing credential-key representation or introducing a conversion layer.
    lionagi/studio/registry.py (load_studio_route_modules) Shared ln.import_module Use shared module-only loading in fixed route order, preserving decorator registration effects.     lionagi/studio/scheduler/subprocess.py (resolve_li_executable) Native operation The resolver reads console_scripts metadata only after checking an absolute interpreter and adjacent li executable. It selects the registered li module without importing entry points, and records exact metadata exception class/text on failure.     lionagi/studio/services/retention_archive.py (_write_member_stream) Native operation The archive member hasher is updated with each exact encoded JSONL row immediately after that row is written to the ZIP stream, then returns count and hexdigest.     Hash and type boundaries¶

    Source Consumer Reason
    lionagi/studio/services/approvals.py _compute_chain_hash concatenated content_hash+previous_hash and its existing zero-valued genesis; ln.compute_chain_hash uses a colon and GENESIS, so it is not the same chain.
    lionagi/studio/services/approvals.py _compute_hmac_sig Keyed HMAC consumes chain_hash+created_at UTF8 bytes and receives hashlib.sha256 as its digest constructor. This keyed interface is distinct from unkeyed compute_hash.
    lionagi/lndl/assembler.py _is_model_cls structural class-with-model_fields admission; a non-BaseModel class can satisfy it, unlike the nominal shared Pydantic helper.
    lionagi/lndl/assembler.py _unwrap_optional local multi-member union preference for the first structural model class, else first non-None member. Shared unwrap_optional deliberately leaves unions with multiple non-None members unchanged.
    lionagi/operations/lndl_middle/lndl_middle.py _render_type generic list/dict get_origin/get_args and structural model_fields formatting, including classes that are not BaseModel subclasses.
    lionagi/models/field_model.py __repr__ the PEP604 UnionType-specific repr branch and existing typing.Union alternative; is_union_type would merge distinct formatting paths.
    lionagi/libs/schema/breakdown_pydantic_annotation.py breakdown_pydantic_annotation list generic origin/element extraction. The nominal Pydantic predicate moved; union helpers are not substitutes for list arguments.
