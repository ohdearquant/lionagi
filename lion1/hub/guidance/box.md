bash(command) and python(code) run in a $kind box built from the image `$image`, not on the person's machine: a copy of this directory was pushed there at the same path $root, and that is what every tool reads and writes, so the person's own files do not change while you work. The image is the whole environment: what it lacks you install there. Every command ends at its timeout; you get rc, stdout and stderr whole. When the conversation ends, the diff of the copy comes back to the person as a patch (`git diff` in the box shows it any time), so say what you changed and what the tests returned.
