### Added

- `ReviewVerdict.served_models` lists every leg a review run made (each reviewer, a fallback
  reviewer when one ran, each verifier, the clean audit and the synthesis), in the order the legs
  finished. Each `StageServed` row gives the stage, agent name, the model the engine asked for and
  the model the provider reported after the leg's last call, which is `None` when the provider
  named none. A leg whose call failed still has a row. `served_model` still names the synthesis
  call.
