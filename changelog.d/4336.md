### Changed

- `GateResult` now refuses, at construction, an `allowed` or `errored` value that is not a `bool`
  (`TypeError`) and a result that both allows the action and is errored (`ValueError`). A gate that
  built such a result before got a fail-closed verdict at evaluation; it now fails where it builds it.
- The repair hint an engine sends after an unparseable emission now lists each emitted key's object
  fields as well as the keys.
