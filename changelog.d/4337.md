### Fixed

- A child agent's `kkernel mcp` server is now started with `--actor agent:<profile>` (or `agent:anonymous`), replacing any `--actor` or `--namespace` in its configured arguments. This sets the child's default namespace as well as its attribution: khive reads and writes that name no namespace now use `agent:<profile>`, where before they used the actor configured in the child's working directory, or `local`. Records a child wrote before this change stay in the namespace they were written to. A server entry with no argument list, or one that does not run the `mcp` subcommand, gets only the `KHIVE_ACTOR` variable, which sets attribution and leaves the namespace as before.
