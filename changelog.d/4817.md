### Changed

- A profile or Studio library file whose first line starts with `---` but is not a bare `---` (such as `--- # agent` or `---settings`) has no frontmatter, and settings that sat after such a line are no longer read. The frontmatter reader returns the whole file as the body, the strict save-time check refuses the file with "frontmatter opening line must be a bare ---", and loading the profile warns that its settings are ignored, or refuses when they set tools, `deny_read` or `mcp`. Before, the block between the next two bare `---` lines was read as the file's settings and the lines above it were dropped.
- The frontmatter readers always drop a leading byte-order mark from the body they return, including when no frontmatter follows it.
