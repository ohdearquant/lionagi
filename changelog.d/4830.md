### Added

- `python -m lionhub.providers.openai.codex_tools_probe --candidate '<codex args>' ...` measures
  which sets of codex arguments leave the model no tool but those of the one MCP server named on
  the command line, read from the `tools` array of every Responses request codex sends to a
  loopback stand-in. Each candidate is one run and one row beside a native and an ambient
  control. The table is written to `LIONAGI_HOME/codex-tools-probes`, keyed by the binary's path,
  version and bytes. No launch reads it.
