### Added

- `python -m lionhub.providers.openai.codex_exec_capture --out <new directory>` records what
  `codex exec --json` writes for fixed prompts (a run asked to write nothing, a run naming an
  unknown model, and with `--hook-case` a run whose prompt a hook in a scratch codex home
  blocks), read-only and with no MCP server, so the cases can be told apart from captured
  output. Each command line is printed before it runs, nothing is written outside `--out`, and
  no sign-in file is read.
