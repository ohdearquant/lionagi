### Added

- A leg-host launch may name a subscription account with `action_account`, and `li remote run`
  takes `--account`. The leg host refuses a name `li agent --account` would refuse, checked
  against its own accounts directory, and runs the leg with `li agent --account`. The launch
  response echoes the account and `GET /api/launches/capabilities` reports `named_account`;
  `li remote run --account` refuses a host without it and cancels a launch whose response does not
  confirm the account.

### Changed

- A leg-host leg's environment now carries the daemon's `LIONAGI_HOME` and `LIONAGI_LOGINS_DIR`,
  so the leg finds subscription accounts in the directory the daemon is configured with.
