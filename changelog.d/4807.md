### Changed

- `lionagi.adapters.async_postgres_adapter` moves to `lionhub.integrations.postgres_adapter`. With lionhub installed, the old import path still works with a deprecation warning and returns the same module; it is removed in 2.0.0. Without lionhub, importing the old path raises `ModuleNotFoundError` for `lionhub`.
- Requesting the `lionagi_async_pg` adapter from `Node.adapt_to_async` or `Node.adapt_from_async` now raises when the adapter cannot be registered, where it used to register nothing and fail at the lookup. A missing `postgres` extra, or a missing lionhub, raises the `ImportError` that names the extra; any other failure propagates. A request after a failure tries the registration again.
