### Changed

- `collect_api_turn` takes an optional keyword-only `estimate_cost`. Without it, core records a turn's tokens with cost and pricing version `None`; the lionhub CLI agent passes `estimate_response_cost`, so its usage records stay priced.
- `estimate_response_cost` moves from the private `lionagi.service._api_telemetry` to `lionagi.service.accounts._pricing`.
- Core modules outside `lionagi.service.accounts` import only its seam: the shared types, the routing scope, the new request guard (`_request_guard`, moved from `_router`, which re-imports it) and the new usage-shape helpers (`_usage_shape`, with `cache_write_split` and `CACHE_WRITE_LIFETIMES`).
