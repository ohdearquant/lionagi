### Changed

- The claude tools probe's launch flags begin with
  `--settings '{"env":{"ENABLE_TOOL_SEARCH":"false"}}'`, so `claude` offers no placeholder for
  tools it would load on demand; `--extra-flag` refuses a second `--settings`.
- The codex tools probe's MCP flags approve the one server's tools with
  `mcp_servers.<server>.default_tools_approval_mode="approve"`, so its calls run under an
  approval policy of `never`.
