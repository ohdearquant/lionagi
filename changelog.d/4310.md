### Fixed

- The pre-turn khive recall, feedback, compose and writeback client that a profile-driven agent registers now acts as `agent:<profile>` (or `agent:anonymous`), the same actor its forwarded khive servers already use, instead of as whoever launched the process. `KhiveInjectionProvider` takes an optional `actor` and sets `KHIVE_ACTOR` in the environment of the khive MCP server it spawns, replacing any value configured there; without an actor the server is left as configured. An agent built without a profile is unchanged.
