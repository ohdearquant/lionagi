### Changed

- `lionagi.service.accounts._credentials` moves to `lionhub.providers.anthropic.accounts._credentials`; the old import path is removed in 2.0.0.
- `lionagi.service.accounts._ledger` moves to `lionhub.providers.anthropic.accounts._ledger`; the old import path is removed in 2.0.0. The ledger keeps its logger name `lionagi.service.accounts._ledger`, and its store file and schema do not change.
- `lionagi.service.accounts._pricing` moves to `lionhub.providers.anthropic.accounts._pricing`; the old import path is removed in 2.0.0.
- `lionagi.service.accounts._router` moves to `lionhub.providers.anthropic.accounts._router`; the old import path is removed in 2.0.0.
- `lionagi.service.accounts` keeps the routing seam the core reads: the shared types, the routing scope, the request guard and the usage-shape helpers. Without the hub installed, the core has no account engine.
