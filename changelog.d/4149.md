### Fixed

- On Python 3.14.7 and 3.14.8, the log no longer carries the text of an exception raised by cleanup
  or acknowledgement work that failed after the task waiting on it was cancelled. That text could
  include the output of a failed secret lookup; the framework records such a failure itself and logs
  only its type. On every Python version, such a failure is also no longer logged as "exception was
  never retrieved" when nothing awaited it.
