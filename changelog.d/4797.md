### Added

- `LIONAGI_SCHEDULER_HOLD`: set to a true value, the daemon serves its API with the scheduler engine not started, so schedules can be listed, disabled and enabled while none of them fires. Unset or false, startup is unchanged; any other value stops the start with an error naming the variable. A disabled row stays disabled at the next normal start, a cron row enabled under the hold gets its next fire recomputed, and other rows keep their missed-fire policy.
