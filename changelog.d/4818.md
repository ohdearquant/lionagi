### Fixed

- A profile whose frontmatter cannot be read is now refused when it spells a protected key with YAML escapes, such as `"\x74ools"` for `tools` or `"deny\x5fread"` for `deny_read`, the same way as when the key is written plainly. This covers a block after the prompt text, a block behind text ahead of `---` on the first line, and `deny_read` in a body block. Studio treats an escaped `lion_system` key in an unreadable agent file as a mention and protects the file.
