### Changed

- The process identity, signalling and recorded-worker cleanup helpers moved from
  `lionagi/cli/kill.py` to `lionagi/cli/_kill_service.py`; the helpers used outside the
  command dropped their leading underscore there (`kill_one`, `list_running_children`,
  `check_pid_identity` and others). `lionagi.cli.kill` keeps the names its own code uses,
  under their old names; its other private helpers are now importable only from
  `lionagi.cli._kill_service`. The Studio cancel path and `li state doctor` import from the
  new module, so Studio no longer imports the kill command.
