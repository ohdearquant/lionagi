### Changed

- `lionagi.state` moves to `lionhub.state`; the old import path is removed in 2.0.0.
- `lionagi._log_channels` moves to `lionhub.state.log_channels`; the old import path is removed in 2.0.0.
- `lionagi._cli_worker_context` moves to `lionhub.state.cli_worker_context`; the old import path is removed in 2.0.0.
- `lionagi.hooks._message_retry` moves to `lionhub.state.message_retry`; the old import path is removed in 2.0.0.
- `lionagi.hooks._persistence_handlers` moves to `lionhub.orchestration.run_persistence`: the five `persist_*` handlers leave `lionagi.hooks.builtins`, which forwards their names with a deprecation warning until they are removed in 2.0.0. `lionhub.orchestration.run_persistence` registers them when it is imported.
- `SessionObserver.bind_db_persistence` called without `db=` writes nothing and logs a warning, instead of opening a store for each signal.
