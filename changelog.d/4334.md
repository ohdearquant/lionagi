### Changed

- Checkpoint patch replay rebuilds an object's member table once for consecutive operations on its members, instead of once per operation; the result is unchanged.
- The rule for when session statistics reuse a progression's stored JSON is stated in one helper and pinned by a table of encodings checked against SQLite's own membership.

### Fixed

- Message persistence rejects non-string and empty message IDs before writing when appending them to progressions.
