### Changed

- A Codex home named in `codex_home` by a profile under `~/.lionagi/agents` is now denied to a
  sandboxed Claude Code child, like the homes in the accounts directory. A global profile file that
  cannot be parsed now refuses the launch instead of leaving its home readable.
- A project profile under `.lionagi/agents` is now refused when it shares its name with a global
  profile that sets `account` or `codex_home`, because loading it would silently drop that account.
  Rename it or remove it; a global profile that names no account can still be shadowed.
- The agent profile list, and the MCP `profile_list` result, now leave out a profile refused for
  its account settings and name it with the reason, instead of failing for every profile.
- The account refusal message now says to move the setting to a profile under `~/.lionagi/agents`
  or remove it.
