### Changed

- A `Session` used through the SDK no longer writes to the state store: `lionagi.hooks.DEFAULT_HOOKS` is empty, so
  a session's hook bus starts with no handlers. Runs started through the hub (the CLI and the MCP server's agent
  runs) still record their sessions and branches, through
  `lionhub.orchestration.run_persistence.install_run_persistence`. To keep the old behaviour in SDK code, wire the
  handlers by name, for example `build_session_bus({"session.start": ["persist_session_start"]})`.
