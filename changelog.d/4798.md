### Changed

- lionagi, the Studio backend and the agent workbench require Python 3.11 or later. Python 3.10
  reached end of life in October 2026, and the fixed dnspython release supports 3.11 and later
  only. CI and the release workflow test 3.11 through 3.14 for 1.0.0 and later releases.

### Security

- Dependency floors move to fixed releases: `opentelemetry-api` 1.45.2 (GHSA-mf5v-w3w3-f6cg,
  quadratic-time `traceparent` parsing), `dnspython` 2.9.2 (GHSA-vvf4-9x63-8xvv, excessive memory
  and CPU use) and `joserfc` 1.7.6 (GHSA-jpxq-7h8p-2q76 and GHSA-9pg5-8c7x-5hfx, unbounded JWE
  recipients and an oversized compact JWS allocation).

- The Studio frontend and the VS Code extension lock `minimatch` 11.0.1 or later
  (GHSA-g3hv-75wg-m249, glob pattern amplification), and the Studio frontend locks `seroval`
  1.6.11 or later (GHSA-f86p-h4j2-7qgj and GHSA-9wx9-5pv9-3349, code and script injection in
  serialized output).
