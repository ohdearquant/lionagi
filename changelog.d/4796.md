### Changed

- `lionagi.service._model_spec` moves to `lionhub.providers.model_spec`: the CLI provider tables (backend aliases, the effort, fast, bypass, yolo and repository kwargs, the Claude, Codex and Gemini effort clamps), `parse_model_spec` and `codex_unset_effort_default`. With lionhub installed, importing these names from `lionagi.service.providers` still works with a deprecation warning; the old import path is removed in 2.0.0. Without lionhub that import raises `ModuleNotFoundError`, where `codex_unset_effort_default` used to return `None`.
- `lionagi.service.providers` keeps the effort-suffix grammar: `EFFORT_LEVELS`, `normalize_effort` and `split_effort_suffix`.
- `iModel` reads an effort suffix through the endpoint class's `effort_kwarg` (and its `clamp_effort` when it has one); a model string for a provider whose endpoint declares neither passes through unchanged without importing the hub.
