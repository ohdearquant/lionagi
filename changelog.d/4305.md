### Fixed

- A khive MCP server that `li agent`, the `li o flow` orchestrator and workers, `li o fanout`, or a reactively spawned flow node hands to a child agent now carries `KHIVE_ACTOR=agent:<profile>` (or `agent:anonymous`) in its environment, replacing any value configured there, so the child no longer acts anonymously or as whoever launched it. This includes codex workers that ignore the user config. The server is also given `--actor` with the same value, so an actor config in the child's working directory does not take precedence; a server entry with no argument list keeps only the variable, which such a config overrides. A node spawned from a branch the run did not register, such as a resumed orchestrator, acts as `agent:anonymous`, and the pre-turn khive recall and writeback client is not yet attributed.
