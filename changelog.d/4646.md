### Fixed

- `li mcp serve` loads every module its verbs use before it answers anything. If one
  of its own modules cannot be imported, at start or later because the installed
  source changed under it, the server exits with code 78 and a message naming the
  module instead of answering with some verbs refused, so the client starts a fresh
  server. A verb that needs a package which is not installed is reported on its
  catalog entry as before.
