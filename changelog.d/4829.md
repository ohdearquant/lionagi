### Added

- `python -m lionhub.providers.anthropic.claude_tools_probe` records whether a `claude` binary,
  given `--tools ""`, `--strict-mcp-config` and one server in `--mcp-config`, offers its model no
  tool but that server's, read from the tool list of every model request it sends to a loopback
  stand-in. The record is written to `LIONAGI_HOME/claude-tools-probes`, keyed by the binary's
  path, version and bytes. No launch reads it yet.
