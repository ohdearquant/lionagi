### Added

- `global/NAME` runs `~/.lionagi/playbooks/NAME.playbook.yaml` even when a project-local playbook of the same name would hide it, from `li play` and `play.submit` alike. An active plugin named `global` that declares `NAME` keeps that token.
- A play's session record keeps the playbook file that ran (`playbook_path`) and, when a project-local file hid the global one, the global file (`playbook_shadowed`) in its node metadata. The shadow warning now names the `global/NAME` spelling.
