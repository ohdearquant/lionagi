### Changed

- The codex sandbox probe tries every denied location in `child_sandbox.deny_read` that exists
  on the host, with no cap: a file is opened for zero bytes and a directory is listed. The probe
  record states how many it opened of how many are present, and a launch refuses a record whose
  deny arm opened none; that refusal says to add a file or directory this account can read.
- Probe records written before this release (format 6 or earlier) no longer let a codex child
  launch under lionagi's permission profile. Probe again after upgrading:
  `python -m lionhub.providers.openai.codex_sandbox_probe`.
