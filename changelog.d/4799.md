### Changed

- `lionagi.libs.frontmatter` moves to `lionhub.orchestration.frontmatter`. With lionhub installed, the old import path still works with a deprecation warning and returns the same module; it is removed in 2.0.0.
- `lionagi._auto`, the CLI command declaration types and the `auto_register` decorator, moves to `lionhub.serve.cli.registration`. With lionhub installed, `import lionagi._auto` still works with a deprecation warning and returns the new module, and its deprecated catalog functions still forward to `lionhub.serve.cli.catalog`; the old path is removed in 2.0.0. Without lionhub, importing either old path raises `ModuleNotFoundError` for `lionhub`.
