### Changed

- The claude tools probe's control run passes when `claude` offers `Bash`, and says whether the
  server's tool was offered beside it. Each record keeps, per offered tool, its name, the keys of
  its definition, its scalar values and the byte lengths of its description and schema, never
  their text. `--extra-flag '<flag> [value]'`, repeatable, adds a flag to all three runs; the
  flags are written into the record and give it a file of its own. Records are format 2.
- The codex tools probe's control run passes on any tool of codex's own, and its ambient arm
  counts a user server as loaded when the server answered `tools/list` even if its tool was not
  offered.
